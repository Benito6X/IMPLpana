⚙️ Configuración
Tu cuenta, los códigos de acceso para empleados y exportar tus datos.
Mi Cuenta

Tu contraseña nunca se guarda en este archivo — vive únicamente en Supabase Auth.

Equipo

Para agregar a otro dueño o programador: crea su cuenta desde Supabase → Authentication → Users → Add user, y luego asignale el rol aquí. Programador tiene acceso total, incluyendo cosas que ni el dueño puede hacer (como borrar el registro de actividad) — solo otro programador puede otorgar o quitar ese rol.

Registro de Actividad

Solo vos como programador ves esta tarjeta y podés borrar el historial completo. El dueño nunca la ve.

Roles (jerarquía de acceso)

Los roles van de menor a mayor acceso, como en una empresa: cada nivel incluye lo del nivel anterior y suma más. Nivel 1 es la base (Leads, Visitas, WhatsApp, Reseñas); a partir de nivel 2 se puede editar valor y etiquetas de un lead; a partir de nivel 3 se puede eliminar leads. Crea los roles que necesites — no estás limitado a los 3 que vienen por defecto.

Empleados (acceso por código)

Genera un código para cada persona y asignale un rol de la lista de arriba. Entran con ese código (sin correo ni contraseña). Nadie con código llega a Configuración — eso es solo para cuentas de dueño. Cada acción queda en su log.
